# STM32 Snake Game (FreeRTOS)

This project implements a real-time Snake game on an STM32 microcontroller using FreeRTOS.

## Features
- Task-based game logic using FreeRTOS
- UART-based input control
- OLED display output (SSD1306)

## Technologies
- C
- FreeRTOS
- STM32 HAL

## Description
The system is designed using multiple tasks to handle snake movement and score updates concurrently, demonstrating real-time embedded system design.
